# AGENTS.md

This repository is dedicated to the development of client-rendered web games, focusing on single-player and local multiplayer experiences.

## Project Focus

- **Client-Rendered:** All game logic and rendering happen in the browser.
- **Game Types:** Single-player adventures, puzzles, and local multiplayer (shared screen/keyboard).

## Agent Guidelines

- **Input Handling:** Implement flexible input systems that support keyboard, mouse, and gamepad for local multiplayer.
